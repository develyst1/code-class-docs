# คลาส 01 — จากขั้นตอนสู่โปรแกรม: เครื่องมือ ข้อมูล ตัวแปร รับค่า-คำนวณ-แสดงผล

**เป้าหมาย:** เขียนขั้นตอน 1-2-3 ของโจทย์ แล้วแปลงเป็นโปรแกรมคำนวณตัวแรกที่รันได้

ตลอด 4 คลาสแรก เราจะสร้างโปรแกรมเดียวกันให้โตขึ้นทีละคลาส คือ **โปรแกรมคิดเงินของร้านค้า** วันนี้คือรุ่นที่ 1

## โจทย์วันนี้

ลูกค้าซื้อของชิ้นเดียวกันหลายชิ้น ร้านอยากรู้ว่าต้องเก็บเงินเท่าไร ให้โปรแกรมถามราคาต่อชิ้นกับจำนวนชิ้น แล้วบอกยอดรวม

## ขั้นตอน 1-2-3

ก่อนเขียนโค้ด เขียนเป็นภาษาไทยก่อนว่าคนคิดเงินทำอะไรบ้าง ทีละข้อ ตามลำดับ

1. ถามราคาต่อชิ้น
2. ถามจำนวนชิ้น
3. เอาราคาคูณจำนวน
4. บอกยอดรวม

รายการขั้นตอนที่ทำตามลำดับแบบนี้ เรียกว่า **อัลกอริทึม (algorithm)** ส่วน **โปรแกรม** ก็คือขั้นตอนแบบเดียวกันนี้ เขียนในภาษาที่คอมพิวเตอร์อ่านได้ คอมพิวเตอร์จะทำทีละบรรทัด จากบนลงล่าง

### 1. ให้โปรแกรมพูด: `print`

```python
print("สวัสดีร้านค้า")
```

**ผลที่ได้:**
```
สวัสดีร้านค้า
```

`print` แปลว่า แสดงข้อความออกทางหน้าจอ ข้อความต้องอยู่ในเครื่องหมายคำพูด `" "`

### 2. เก็บค่าไว้ในชื่อ: ตัวแปร

```python
price = 50
qty = 3
total = price * qty
print(total)
```

**ผลที่ได้:**
```
150
```

**ตัวแปร (variable)** คือชื่อที่เราตั้งไว้เก็บค่า `price = 50` แปลว่า "ให้ชื่อ `price` เก็บค่า 50" เครื่องหมาย `*` คือคูณ

### 3. ถามผู้ใช้: `input` และกับดักข้อความกับตัวเลข

```python
price = input("ราคาต่อชิ้น (บาท): ")
print(price * 2)
```

**ผลที่ได้** (พิมพ์ `50` แล้วกด Enter):
```
ราคาต่อชิ้น (บาท): 50
5050
```

`input` แปลว่า ถามผู้ใช้ แล้วรอให้พิมพ์ตอบ แต่สิ่งที่ได้จาก `input` เป็น **ข้อความ** เสมอ ไม่ใช่ตัวเลข ข้อความ `"50"` คูณ 2 จึงได้ `"50"` ต่อกันสองครั้ง = `5050` ไม่ใช่ 100

ข้อมูลแต่ละอย่างมี **ชนิด** ของมัน:
- `str` — ข้อความ เช่น `"50"`, `"สวัสดี"`
- `int` — จำนวนเต็ม เช่น `3`
- `float` — ตัวเลขมีทศนิยม เช่น `49.50`

วิธีแก้คือแปลงข้อความเป็นตัวเลขก่อนคำนวณ ด้วย `float()` (มีทศนิยมได้ ใช้กับราคา) หรือ `int()` (จำนวนเต็ม ใช้กับจำนวนชิ้น)

```python
price = float(input("ราคาต่อชิ้น (บาท): "))
print(price * 2)
```

**ผลที่ได้** (พิมพ์ `50`):
```
ราคาต่อชิ้น (บาท): 50
100.0
```

### 4. แสดงเงินให้สวย: f-string

```python
total = 150
print(f"ยอดรวม {total:.2f} บาท")
```

**ผลที่ได้:**
```
ยอดรวม 150.00 บาท
```

**f-string** คือข้อความที่ขึ้นต้นด้วย `f` แล้วใส่ตัวแปรไว้ใน `{ }` ได้ ส่วน `:.2f` แปลว่า แสดงทศนิยม 2 ตำแหน่ง

### 5. รวมเป็นโปรแกรมคิดเงิน รุ่นที่ 1

เทียบกับขั้นตอน 1-2-3 ข้างบน ทีละบรรทัด (ข้อความหลังเครื่องหมาย `#` คือ **คอมเมนต์** โน้ตสำหรับคนอ่าน คอมพิวเตอร์ข้ามไป)

```python
# โปรแกรมคิดเงิน รุ่นที่ 1 (จบคลาส 01)
# ① ถามราคาต่อชิ้น  ② ถามจำนวนชิ้น  ③ คูณกัน  ④ แสดงยอดรวม

price = float(input("ราคาต่อชิ้น (บาท): "))  # ①
qty = int(input("จำนวนชิ้น: "))               # ②
total = price * qty                          # ③
print(f"ยอดรวม {total:.2f} บาท")              # ④
```

**ผลที่ได้** (พิมพ์ `50` แล้ว `3`):
```
ราคาต่อชิ้น (บาท): 50
จำนวนชิ้น: 3
ยอดรวม 150.00 บาท
```

## เรื่องเดียวกันใน JavaScript

ขั้นตอนเหมือนเดิมทุกข้อ ต่างกันแค่วิธีเขียน รอบนี้ใช้ตัวเลขที่กำหนดไว้ในโค้ดแทนการพิมพ์ เพราะการรับค่าใน JavaScript ต้องใช้โค้ดที่ยากกว่าคลาสนี้

```js
// โปรแกรมคิดเงิน รุ่นที่ 1 แบบ JavaScript (จบคลาส 01)
// ใช้ตัวเลขที่กำหนดไว้ในโค้ด แทนการพิมพ์รับค่า

let price = 50;                                // ① ราคาต่อชิ้น
let qty = 3;                                   // ② จำนวนชิ้น
let total = price * qty;                       // ③ คูณกัน
console.log(`ยอดรวม ${total.toFixed(2)} บาท`);  // ④ แสดงยอดรวม
```

รันด้วย `node bill_v1.js`

**ผลที่ได้:**
```
ยอดรวม 150.00 บาท
```

| Python | JavaScript | ความหมาย |
|---|---|---|
| `price = 50` | `let price = 50;` | สร้างตัวแปร |
| `print(...)` | `console.log(...)` | แสดงผล |
| `f"ยอดรวม {total:.2f} บาท"` | `` `ยอดรวม ${total.toFixed(2)} บาท` `` | ใส่ตัวแปรในข้อความ ทศนิยม 2 ตำแหน่ง |
| `# ...` | `// ...` | คอมเมนต์ |

## แบบฝึกหัด

### แบบฝึกหัด 1 (เขียนโค้ด): คิดเงินทอน

ต่อจากโปรแกรมรุ่นที่ 1: หลังแสดงยอดรวม ให้ถาม `รับเงินมา (บาท): ` แล้วแสดง `เงินทอน <จำนวน> บาท`

ลองป้อน `50`, `3`, `200` ต้องได้:
```
ราคาต่อชิ้น (บาท): 50
จำนวนชิ้น: 3
ยอดรวม 150.00 บาท
รับเงินมา (บาท): 200
เงินทอน 50.00 บาท
```

<details>
<summary>ดูเฉลย</summary>

ขั้นตอนที่เพิ่ม: ⑤ ถามเงินที่รับมา ⑥ เอาเงินที่รับมาลบยอดรวม ⑦ แสดงเงินทอน

```python
price = float(input("ราคาต่อชิ้น (บาท): "))
qty = int(input("จำนวนชิ้น: "))
total = price * qty
print(f"ยอดรวม {total:.2f} บาท")
paid = float(input("รับเงินมา (บาท): "))
change = paid - total
print(f"เงินทอน {change:.2f} บาท")
```

</details>

## ช่วงใช้ AI

**AI** ในคอร์สนี้คือโปรแกรมแชตที่ตอบคำถามได้ (ใช้แบบฟรีตัวไหนก็ได้) วันนี้ให้มันช่วยอธิบายโค้ด

1. คัดลอกโค้ดใน [examples/bill_v1.py](examples/bill_v1.py) ไปวางในแชต แล้วพิมพ์ต่อท้าย:
   ```
   อธิบายโค้ดนี้ทีละบรรทัดเป็นภาษาไทยสำหรับมือใหม่
   ```
2. ตรวจคำตอบของ AI กับที่เราเรียนวันนี้ ก่อนเชื่อ:
   - บอกไหมว่า `input` ได้ค่าเป็นข้อความ จึงต้องใช้ `float()` และ `int()`
   - อธิบาย `:.2f` ว่าทศนิยม 2 ตำแหน่งไหม
   - มีตรงไหนที่ AI อธิบายไม่ตรงกับผลที่เรารันได้จริงไหม ถ้ามี ให้เชื่อผลที่รันได้
3. **ห้ามส่งให้ AI:** รหัสผ่าน ข้อมูลส่วนตัวของใคร และโค้ดหรือข้อมูลจากที่ทำงาน

## สรุป

- โปรแกรมคือขั้นตอน 1-2-3 ที่คอมพิวเตอร์ทำตามทีละบรรทัด เขียนขั้นตอนเป็นภาษาไทยก่อนเสมอ
- `input` ได้ข้อความ ต้องแปลงด้วย `float()` หรือ `int()` ก่อนคำนวณ แล้วแสดงผลด้วย `print` และ f-string
- JavaScript ใช้ขั้นตอนเดียวกัน ต่างกันแค่วิธีเขียน
