# คลาส 02 — การตัดสินใจและการทำซ้ำ

**เป้าหมาย:** ให้โปรแกรมคำนวณเลือกทำตามเงื่อนไข (เช่น ส่วนลด) และถามซ้ำจนกว่าจะสั่งเลิก

## ทวนคลาสที่แล้ว

- โปรแกรมคือขั้นตอน 1-2-3 ที่คอมพิวเตอร์ทำทีละบรรทัด จากบนลงล่าง
- `input` ได้ข้อความเสมอ ต้องแปลงด้วย `float()` หรือ `int()` ก่อนคำนวณ
- แสดงเงินทศนิยม 2 ตำแหน่งด้วย f-string `f"{total:.2f}"`
- โปรแกรมรุ่นที่ 1: [bill_v1.py](../01-from-steps-to-program/examples/bill_v1.py) ถามราคากับจำนวน แล้วบอกยอดรวม

## โจทย์วันนี้

ร้านมีโปรโมชัน ซื้อครบ 1000 บาทลด 10 % ซื้อครบ 500 บาทลด 5 % และร้านไม่อยากเปิดโปรแกรมใหม่ทุกครั้งที่มีลูกค้า ให้โปรแกรมคิดเงินลูกค้าทีละคนไปเรื่อย ๆ จนกว่าจะพิมพ์ราคาเป็น 0 เพื่อปิด

## ขั้นตอน 1-2-3

1. ถามราคาต่อชิ้น ถ้าพิมพ์ 0 ให้ปิดโปรแกรม
2. ถามจำนวนชิ้น
3. คิดยอดรวม
4. ถ้ายอดรวมตั้งแต่ 1000 ขึ้นไป ลด 10 % · ถ้าตั้งแต่ 500 ขึ้นไป ลด 5 % · ถ้าน้อยกว่านั้น ไม่ลด
5. แสดงยอดรวม ส่วนลด และยอดที่ต้องจ่าย
6. กลับไปข้อ 1

ข้อ 4 คือ **การตัดสินใจ** (โปรแกรมเลือกทำตามเงื่อนไข) ส่วนข้อ 6 คือ **การทำซ้ำ** (วนกลับไปทำขั้นตอนเดิม) สองเรื่องนี้มีในทุกภาษา

## แปลงเป็นโค้ด (Python)

### 1. เปรียบเทียบค่า

```python
total = 600
print(total >= 500)
print(total >= 1000)
print(total == 600)
```

**ผลที่ได้:**
```
True
False
True
```

การเปรียบเทียบให้คำตอบเป็น `True` (จริง) หรือ `False` (เท็จ) เครื่องหมายที่ใช้บ่อย: `>=` มากกว่าหรือเท่ากับ · `<` น้อยกว่า · `==` เท่ากับ (สองตัว เพราะ `=` ตัวเดียวใช้เก็บค่าลงตัวแปร) · `!=` ไม่เท่ากับ

### 2. เลือกทำตามเงื่อนไข: `if` / `elif` / `else`

```python
total = 600
if total >= 1000:
    discount = total * 10 / 100
elif total >= 500:
    discount = total * 5 / 100
else:
    discount = 0
print(discount)
```

**ผลที่ได้:**
```
30.0
```

- `if` แปลว่า "ถ้า" · `elif` แปลว่า "ไม่อย่างนั้น ถ้า" · `else` แปลว่า "ไม่อย่างนั้น"
- Python ตรวจจากบนลงล่าง เจอเงื่อนไขแรกที่เป็นจริงก็ทำข้อนั้นข้อเดียว แล้วข้ามที่เหลือ ดังนั้นต้องเช็ก 1000 ก่อน 500
- บรรทัดที่อยู่ใต้ `if` ต้อง **เยื้อง** เข้าไป (เว้นหน้า 4 ช่อง) เพื่อบอกว่าบรรทัดนั้นเป็นของ `if` ตัวไหน และต้องมี `:` ท้ายบรรทัด `if`

### 3. ทำซ้ำตามจำนวนรอบ: `for` และ `range`

```python
for i in range(1, 4):
    print(f"ลูกค้าคนที่ {i}")
```

**ผลที่ได้:**
```
ลูกค้าคนที่ 1
ลูกค้าคนที่ 2
ลูกค้าคนที่ 3
```

`for` แปลว่า ทำซ้ำทีละค่า · `range(1, 4)` คือตัวเลข 1, 2, 3 (เริ่มที่ 1 และหยุด **ก่อน** ถึง 4)

### 4. ไล่โปรแกรมทีละรอบด้วยตาราง

เวลาอ่านลูปแล้วงง ให้ทำตาราง: **หนึ่งแถวต่อหนึ่งรอบ หนึ่งคอลัมน์ต่อหนึ่งตัวแปร** แล้วเขียนค่าทีละรอบด้วยมือ นี่คือวิธีอ่านอัลกอริทึมที่ใช้ได้กับทุกโปรแกรม

ตารางของลูป `for` ข้างบน:

| รอบ | `i` | แสดงผล |
|---|---|---|
| 1 | 1 | ลูกค้าคนที่ 1 |
| 2 | 2 | ลูกค้าคนที่ 2 |
| 3 | 3 | ลูกค้าคนที่ 3 |

### 5. ทำซ้ำจนกว่าจะสั่งหยุด: `while` และ `break`

ลูกค้าจะมากี่คนเราไม่รู้ล่วงหน้า จึงใช้ `while True` (ทำซ้ำไปเรื่อย ๆ) แล้วใช้ `break` (ออกจากลูป) เมื่อพิมพ์ 0

```python
while True:
    price = float(input("ราคาต่อชิ้น (บาท, 0 = ปิด): "))
    if price == 0:
        print("ปิดโปรแกรม")
        break
    print(f"ได้ราคา {price:.2f} บาท")
```

**ผลที่ได้** (พิมพ์ `50` แล้ว `0`):
```
ราคาต่อชิ้น (บาท, 0 = ปิด): 50
ได้ราคา 50.00 บาท
ราคาต่อชิ้น (บาท, 0 = ปิด): 0
ปิดโปรแกรม
```

### 6. รวมเป็นโปรแกรมคิดเงิน รุ่นที่ 2

```python
# โปรแกรมคิดเงิน รุ่นที่ 2 (จบคลาส 02)
# ① ถามราคา (0 = ปิด)  ② ถามจำนวน  ③ ยอดรวม  ④ คิดส่วนลด  ⑤ แสดงผล  ⑥ กลับไป ①

while True:                                        # ⑥ ทำซ้ำไปเรื่อย ๆ
    price = float(input("ราคาต่อชิ้น (บาท, 0 = ปิด): "))      # ①
    if price == 0:
        print("ปิดโปรแกรม")
        break
    qty = int(input("จำนวนชิ้น: "))                  # ②
    total = price * qty                            # ③
    if total >= 1000:                              # ④
        discount = total * 10 / 100
    elif total >= 500:
        discount = total * 5 / 100
    else:
        discount = 0
    pay = total - discount
    print(f"ยอดรวม {total:.2f} บาท · ส่วนลด {discount:.2f} บาท · ต้องจ่าย {pay:.2f} บาท")  # ⑤
```

**ผลที่ได้** (ลูกค้า 3 คน: `300` กับ `2` · `1000` กับ `1` · `60` กับ `2` แล้วพิมพ์ `0`):
```
ราคาต่อชิ้น (บาท, 0 = ปิด): 300
จำนวนชิ้น: 2
ยอดรวม 600.00 บาท · ส่วนลด 30.00 บาท · ต้องจ่าย 570.00 บาท
ราคาต่อชิ้น (บาท, 0 = ปิด): 1000
จำนวนชิ้น: 1
ยอดรวม 1000.00 บาท · ส่วนลด 100.00 บาท · ต้องจ่าย 900.00 บาท
ราคาต่อชิ้น (บาท, 0 = ปิด): 60
จำนวนชิ้น: 2
ยอดรวม 120.00 บาท · ส่วนลด 0.00 บาท · ต้องจ่าย 120.00 บาท
ราคาต่อชิ้น (บาท, 0 = ปิด): 0
ปิดโปรแกรม
```

## เรื่องเดียวกันใน JavaScript

ใช้ยอดรวม 600 ที่กำหนดไว้ในโค้ด ผ่าน `if` ชุดเดียวกัน แล้วนับลูกค้า 1 ถึง 3 ด้วย `for`

```js
// โปรแกรมคิดเงิน รุ่นที่ 2 แบบ JavaScript (จบคลาส 02)
// ใช้ยอดรวมที่กำหนดไว้ในโค้ด แทนการพิมพ์รับค่า

let total = 600;
let discount;
if (total >= 1000) {
  discount = total * 10 / 100;
} else if (total >= 500) {
  discount = total * 5 / 100;
} else {
  discount = 0;
}
let pay = total - discount;
console.log(`ยอดรวม ${total.toFixed(2)} บาท · ส่วนลด ${discount.toFixed(2)} บาท · ต้องจ่าย ${pay.toFixed(2)} บาท`);

// การทำซ้ำด้วย for: นับ 1 ถึง 3
for (let i = 1; i <= 3; i++) {
  console.log(`ลูกค้าคนที่ ${i}`);
}
```

รันด้วย `node bill_v2.js`

**ผลที่ได้:**
```
ยอดรวม 600.00 บาท · ส่วนลด 30.00 บาท · ต้องจ่าย 570.00 บาท
ลูกค้าคนที่ 1
ลูกค้าคนที่ 2
ลูกค้าคนที่ 3
```

| Python | JavaScript | ความหมาย |
|---|---|---|
| `elif` | `else if` | ไม่อย่างนั้น ถ้า |
| เยื้องบรรทัด + `:` | `{ }` | บอกว่าบรรทัดไหนอยู่ใต้ `if` / `for` |
| `for i in range(1, 4):` | `for (let i = 1; i <= 3; i++)` | นับ 1 ถึง 3 |
| `True` / `False` | `true` / `false` | จริง / เท็จ |

## แบบฝึกหัด

### แบบฝึกหัด 1 (เขียนโค้ด): เพิ่มขั้นส่วนลด

เพิ่มโปรโมชันใหม่ในรุ่นที่ 2: ยอดรวมตั้งแต่ 2000 ขึ้นไป ลด 15 %

ลองป้อน `2000`, `1`, `0` ต้องได้:
```
ราคาต่อชิ้น (บาท, 0 = ปิด): 2000
จำนวนชิ้น: 1
ยอดรวม 2000.00 บาท · ส่วนลด 300.00 บาท · ต้องจ่าย 1700.00 บาท
ราคาต่อชิ้น (บาท, 0 = ปิด): 0
ปิดโปรแกรม
```

<details>
<summary>ดูเฉลย</summary>

เงื่อนไข 2000 ต้องมาก่อน 1000 เพราะ Python ทำเงื่อนไขแรกที่เป็นจริงเท่านั้น ถ้าเอา 1000 ขึ้นก่อน ยอด 2000 จะได้แค่ 10 %

```python
while True:
    price = float(input("ราคาต่อชิ้น (บาท, 0 = ปิด): "))
    if price == 0:
        print("ปิดโปรแกรม")
        break
    qty = int(input("จำนวนชิ้น: "))
    total = price * qty
    if total >= 2000:
        discount = total * 15 / 100
    elif total >= 1000:
        discount = total * 10 / 100
    elif total >= 500:
        discount = total * 5 / 100
    else:
        discount = 0
    pay = total - discount
    print(f"ยอดรวม {total:.2f} บาท · ส่วนลด {discount:.2f} บาท · ต้องจ่าย {pay:.2f} บาท")
```

</details>

ไม่ต้องรันโปรแกรม ให้เขียนตารางไล่โปรแกรมรุ่นที่ 2 เมื่อป้อน `300`, `2` แล้ว `0` (หนึ่งแถวต่อหนึ่งรอบ คอลัมน์: `price` `qty` `total` `discount` `pay` และสิ่งที่แสดง) แล้วค่อยรันเทียบ

<details>
<summary>ดูเฉลย</summary>

| รอบ | `price` | `qty` | `total` | `discount` | `pay` | แสดงผล |

รอบที่ 2 ไม่ได้ถามจำนวน เพราะ `break` ออกจากลูปก่อนถึงบรรทัดนั้น

## ช่วงใช้ AI

1. คัดลอกโค้ดใน [examples/bill_v2.py](examples/bill_v2.py) ไปวางในแชต AI แล้วพิมพ์ต่อท้าย:

   - ลองป้อนตัวเลขที่ AI เสนอจริง แล้วเทียบผลที่ได้กับตารางที่ไล่ด้วยมือ
3. ห้ามส่งรหัสผ่าน ข้อมูลส่วนตัว หรือโค้ดจากที่ทำงานให้ AI

## สรุป

- `if` / `elif` / `else` ให้โปรแกรมเลือกทำ เช็กจากบนลงล่าง และทำเงื่อนไขแรกที่เป็นจริง
- `for` ทำซ้ำตามจำนวนรอบที่รู้ · `while` ทำซ้ำจนกว่าจะ `break`
- อ่านลูปไม่ออก ให้ไล่ด้วยตาราง หนึ่งแถวต่อรอบ หนึ่งคอลัมน์ต่อตัวแปร
