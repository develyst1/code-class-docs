# คลาส 03 — ฟังก์ชัน รายการข้อมูล และอัลกอริทึมพื้นฐาน

**เป้าหมาย:** แบ่งโปรแกรมเป็นชิ้นที่ตั้งชื่อได้ เก็บประวัติผลคำนวณ และหาผลรวม ค่ามากสุด ค้นหา เรียงลำดับได้เอง

## ทวนคลาสที่แล้ว

- `if` / `elif` / `else` เลือกทำตามเงื่อนไข เช็กจากบนลงล่าง
- `while True` ทำซ้ำไปเรื่อย ๆ จนเจอ `break` · `for` ทำซ้ำตามจำนวนรอบ
- อ่านลูปไม่ออก ให้ไล่ด้วยตาราง หนึ่งแถวต่อรอบ หนึ่งคอลัมน์ต่อตัวแปร
- โปรแกรมรุ่นที่ 2: [bill_v2.py](../02-decisions-and-repetition/examples/bill_v2.py) คิดส่วนลด และคิดเงินลูกค้าทีละคนจนพิมพ์ 0

## โจทย์วันนี้

ปิดร้านตอนเย็น เจ้าของร้านอยากรู้ว่าวันนี้มีกี่บิล ได้เงินรวมเท่าไร และบิลไหนใหญ่ที่สุด ให้โปรแกรมจำยอดที่ต้องจ่ายของทุกบิลไว้ แล้วสรุปให้ตอนพิมพ์ 0

## แปลงเป็นโค้ด (Python)

### 1. ฟังก์ชัน: ตั้งชื่อให้ขั้นตอน

```python
def calc_discount(total):
    if total >= 1000:
        return total * 10 / 100
    elif total >= 500:
        return total * 5 / 100
    else:
        return 0

print(calc_discount(600))
print(calc_discount(1000))
print(calc_discount(120))
```

**ผลที่ได้:**
```
30.0
100.0
0
```

**ฟังก์ชัน** คือขั้นตอนชุดหนึ่งที่เราตั้งชื่อไว้ แล้วเรียกใช้กี่ครั้งก็ได้ `def` แปลว่า สร้างฟังก์ชัน · `total` ในวงเล็บคือค่าที่ส่งเข้าไป · `return` คือส่งคำตอบกลับออกมา

### 2. รายการข้อมูล: `list` และ `append`

```python
history = []
history.append(570)
history.append(900)
history.append(120)
print(history)
print(len(history))
print(history[0])
```

**ผลที่ได้:**
```
[570, 900, 120]
3
570
```

**รายการข้อมูล (list)** เก็บหลายค่าไว้ในตัวแปรเดียว · `[]` คือรายการว่าง · `append` คือเพิ่มต่อท้าย · `len` คือนับว่ามีกี่ตัว · `history[0]` คือตัวแรก (นับจาก 0 ไม่ใช่ 1)

### 3. ผลรวม ด้วยมือ

ขั้นตอน: เริ่มที่ 0 แล้วบวกทีละบิล

```python
def my_sum(history):
    result = 0
    for amount in history:
        result = result + amount
    return result

print(my_sum([570, 900, 120]))
```

**ผลที่ได้:**
```
1590
```

| รอบ | `amount` | `result` หลังบวก |
|---|---|---|
| เริ่ม | — | 0 |
| 1 | 570 | 570 |
| 2 | 900 | 1470 |
| 3 | 120 | 1590 |

`for amount in history` แปลว่า หยิบทีละตัวจากรายการ มาไว้ในชื่อ `amount`

### 4. ค่ามากสุด ด้วยมือ

ขั้นตอน: จำตัวที่มากที่สุดที่เจอมาไว้ ถ้าเจอตัวที่มากกว่า ก็จำตัวใหม่แทน

```python
def my_max(history):
    largest = 0
    for amount in history:
        if amount > largest:
            largest = amount
    return largest

print(my_max([570, 900, 120]))
```

**ผลที่ได้:**
```
900
```

| รอบ | `amount` | มากกว่า `largest` ไหม | `largest` หลังรอบนี้ |
|---|---|---|---|
| เริ่ม | — | — | 0 |
| 1 | 570 | ใช่ | 570 |
| 2 | 900 | ใช่ | 900 |
| 3 | 120 | ไม่ | 900 |

เริ่มที่ 0 ได้ เพราะยอดเงินไม่ติดลบ

### 5. ค้นหา ด้วยมือ

ขั้นตอน: ดูทีละตัว ถ้าเจอตัวที่ตรงก็ตอบว่าพบเลย ถ้าดูครบแล้วไม่เจอ ตอบว่าไม่พบ

```python
history = [570, 900, 120]
found = False
for amount in history:
    if amount == 900:
        found = True
print(found)
```

**ผลที่ได้:**
```
True
```

### 6. เรียงลำดับ: บนกระดาษก่อน

เขียนตัวเลข 570, 900, 120 ลงกระดาษ แล้วเรียงด้วยมือ: หาตัวที่น้อยที่สุดในกอง ย้ายไปไว้ข้างหน้า ทำซ้ำกับตัวที่เหลือ

| รอบ | กองที่เหลือ | ตัวน้อยสุด | เรียงแล้ว |
|---|---|---|---|
| 1 | 570, 900, 120 | 120 | 120 |
| 2 | 570, 900 | 570 | 120, 570 |
| 3 | 900 | 900 | 120, 570, 900 |

### 7. แล้วค่อยใช้คำสั่งสำเร็จรูป

ทุกเรื่องข้างบน Python มีคำสั่งทำให้อยู่แล้ว ตอนนี้เรารู้แล้วว่าข้างในมันทำอะไร

```python
history = [570, 900, 120]
print(sum(history))
print(max(history))
print(900 in history)
print(sorted(history))
```

**ผลที่ได้:**
```
1590
900
True
[120, 570, 900]
```

### 8. รวมเป็นโปรแกรมคิดเงิน รุ่นที่ 3

```python
# โปรแกรมคิดเงิน รุ่นที่ 3 (จบคลาส 03)
# เหมือนรุ่นที่ 2 แต่แบ่งเป็นฟังก์ชัน และเก็บยอดที่ต้องจ่ายของทุกบิลไว้ใน history
# พิมพ์ราคา 0 แล้วจะสรุปทุกบิลก่อนปิด


def calc_discount(total):
    if total >= 1000:
        return total * 10 / 100
    elif total >= 500:
        return total * 5 / 100
    else:
        return 0


def my_sum(history):
    result = 0                      # เริ่มที่ 0
    for amount in history:
        result = result + amount    # บวกทีละบิล
    return result


def my_max(history):
    largest = 0                     # เงินไม่ติดลบ จึงเริ่มที่ 0 ได้
    for amount in history:
        if amount > largest:        # เจอบิลที่มากกว่า ก็จำบิลนี้แทน
            largest = amount
    return largest


def summary(history):
    print(f"จำนวนบิล {len(history)} · รวม {my_sum(history):.2f} บาท · บิลสูงสุด {my_max(history):.2f} บาท")
    parts = []
    for amount in sorted(history):
        parts.append(f"{amount:.2f}")
    print("เรียงจากน้อยไปมาก: " + ", ".join(parts))


history = []
while True:
    price = float(input("ราคาต่อชิ้น (บาท, 0 = ปิด): "))
    if price == 0:
        summary(history)
        print("ปิดโปรแกรม")
        break
    qty = int(input("จำนวนชิ้น: "))
    total = price * qty
    discount = calc_discount(total)
    pay = total - discount
    print(f"ยอดรวม {total:.2f} บาท · ส่วนลด {discount:.2f} บาท · ต้องจ่าย {pay:.2f} บาท")
    history.append(pay)
```

`", ".join(parts)` คือเอาข้อความทุกตัวในรายการมาต่อกัน คั่นด้วย `, `

**ผลที่ได้** (ป้อนเหมือนคลาส 02: `300` `2` · `1000` `1` · `60` `2` · `0`):
```
ราคาต่อชิ้น (บาท, 0 = ปิด): 300
จำนวนชิ้น: 2
ยอดรวม 600.00 บาท · ส่วนลด 30.00 บาท · ต้องจ่าย 570.00 บาท
ราคาต่อชิ้น (บาท, 0 = ปิด): 1000
จำนวนชิ้น: 1
ยอดรวม 1000.00 บาท · ส่วนลด 100.00 บาท · ต้องจ่าย 900.00 บาท
ราคาต่อชิ้น (บาท, 0 = ปิด): 60
จำนวนชิ้น: 2
ยอดรวม 120.00 บาท · ส่วนลด 0.00 บาท · ต้องจ่าย 120.00 บาท
ราคาต่อชิ้น (บาท, 0 = ปิด): 0
จำนวนบิล 3 · รวม 1590.00 บาท · บิลสูงสุด 900.00 บาท
เรียงจากน้อยไปมาก: 120.00, 570.00, 900.00

```

## เรื่องเดียวกันใน JavaScript

ใช้ยอด 3 บิลที่กำหนดไว้ในโค้ด หาผลรวมและค่ามากสุดด้วยลูปแบบเดียวกัน แล้วเรียงลำดับ

```js
// โปรแกรมคิดเงิน รุ่นที่ 3 แบบ JavaScript (จบคลาส 03)
// ใช้ยอดที่ต้องจ่ายของ 3 บิลที่กำหนดไว้ในโค้ด

const history = [570, 900, 120];

// ผลรวม: เริ่มที่ 0 แล้วบวกทีละบิล
let sum = 0;
for (const amount of history) {
  sum = sum + amount;
}

// ค่ามากสุด: จำบิลที่มากที่สุดที่เจอมา
let largest = 0;
for (const amount of history) {
  if (amount > largest) {
    largest = amount;
  }
}

console.log(`จำนวนบิล ${history.length} · รวม ${sum.toFixed(2)} บาท · บิลสูงสุด ${largest.toFixed(2)} บาท`);

// เรียงลำดับตัวเลข ต้องบอกวิธีเทียบ (a, b) => a - b
const sorted = history.slice().sort((a, b) => a - b);
console.log(`เรียงจากน้อยไปมาก: ${sorted.join(", ")}`);

// กับดัก: ถ้าไม่บอกวิธีเทียบ JavaScript จะเรียงตัวเลขแบบข้อความ
console.log([100, 20, 3].sort());
```

รันด้วย `node bill_v3.js`

**ผลที่ได้:**
```
จำนวนบิล 3 · รวม 1590.00 บาท · บิลสูงสุด 900.00 บาท
เรียงจากน้อยไปมาก: 120, 570, 900
[ 100, 20, 3 ]
```

**กับดักของ JavaScript:** `[100, 20, 3].sort()` ไม่ได้เรียงจากน้อยไปมาก เพราะถ้าไม่บอกวิธีเทียบ JavaScript จะมองตัวเลขเป็นข้อความ แล้วเรียงตามตัวอักษรตัวแรก ("1" มาก่อน "2" มาก่อน "3") จึงต้องใส่ `(a, b) => a - b` เสมอเวลาเรียงตัวเลข หลักคิดเหมือน Python แต่กับดักต่างกัน

| Python | JavaScript | ความหมาย |
|---|---|---|
| `def my_sum(history):` | `function mySum(history) { }` | สร้างฟังก์ชัน |
| `[570, 900, 120]` | `[570, 900, 120]` | รายการข้อมูล |
| `history.append(x)` | `history.push(x)` | เพิ่มต่อท้าย |
| `len(history)` | `history.length` | นับจำนวน |
| `for amount in history:` | `for (const amount of history)` | หยิบทีละตัว |
| `sorted(history)` | `history.slice().sort((a, b) => a - b)` | เรียงจากน้อยไปมาก |

## แบบฝึกหัด

### แบบฝึกหัด 1: หาค่าน้อยสุด ด้วยมือ

เขียนฟังก์ชัน `my_min(history)` ด้วยลูป (ห้ามใช้ `min`) ลองกับ `[570, 900, 120]` ต้องได้ `120`

<details>
<summary>ดูเฉลย</summary>

ค่าน้อยสุดเริ่มที่ 0 ไม่ได้ เพราะไม่มียอดไหนน้อยกว่า 0 คำตอบจะเป็น 0 เสมอ จึงต้องเริ่มจากตัวแรกของรายการ

```python
def my_min(history):
    smallest = history[0]
    for amount in history:
        if amount < smallest:
            smallest = amount
    return smallest

print(my_min([570, 900, 120]))
```

ผลที่ได้:
```
120
```

</details>

### แบบฝึกหัด 2: ค้นหาบิล

เขียนฟังก์ชัน `has_bill(history, amount)` ที่ตอบว่า `พบ` ถ้ามียอดนั้นในรายการ และ `ไม่พบ` ถ้าไม่มี ลองกับ `[570, 900, 120]`: ค้น `900` ต้องได้ `พบ` · ค้น `50` ต้องได้ `ไม่พบ`

<details>
<summary>ดูเฉลย</summary>

```python
def has_bill(history, amount):
    for bill in history:
        if bill == amount:
            return "พบ"
    return "ไม่พบ"

print(has_bill([570, 900, 120], 900))
print(has_bill([570, 900, 120], 50))
```

ผลที่ได้:
```
พบ
ไม่พบ
```

`return` ในลูปจะออกจากฟังก์ชันทันทีที่เจอ ไม่ต้องดูตัวที่เหลือ ถ้าดูครบแล้วไม่เจอ จึงมาถึงบรรทัด `return "ไม่พบ"`

</details>

## ช่วงใช้ AI

1. คัดลอกฟังก์ชัน `my_max` จากข้อ 4 ไปวางในแชต AI แล้วพิมพ์ต่อท้าย:
   ```
   ไล่การทำงานของฟังก์ชันนี้ทีละขั้น เมื่อส่ง [570, 900, 120] เข้าไป บอกค่าของ largest ทุกรอบ
   ```
2. เทียบคำตอบของ AI กับตารางที่เราไล่เองในข้อ 4:
   - ค่า `largest` ทุกรอบตรงกันไหม (0 → 570 → 900 → 900)
   - รอบที่ 3 AI บอกไหมว่า 120 ไม่มากกว่า 900 จึงไม่เปลี่ยน
   - ถ้าไม่ตรง ให้รันโค้ดจริงพร้อม `print(largest)` ในลูป แล้วเชื่อผลที่รันได้
3. ห้ามส่งรหัสผ่าน ข้อมูลส่วนตัว หรือโค้ดจากที่ทำงานให้ AI

## สรุป

- ฟังก์ชันตั้งชื่อให้ขั้นตอน รับค่าเข้า แล้ว `return` คำตอบออกมา · รายการเก็บหลายค่าในตัวแปรเดียว
- ผลรวม ค่ามากสุด ค้นหา เรียงลำดับ เขียนเองได้ด้วยลูป คำสั่งสำเร็จรูปก็ทำแบบเดียวกันข้างใน
- JavaScript เรียงตัวเลขต้องใส่ `(a, b) => a - b` ไม่อย่างนั้นจะเรียงแบบข้อความ
