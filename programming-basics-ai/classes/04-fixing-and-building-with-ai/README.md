# คลาส 04 — หาจุดผิด และสร้างงานกับ AI

**เป้าหมาย:** อ่านข้อความแจ้งข้อผิดพลาดแล้วแก้เองได้ และโปรแกรมคำนวณของตัวเองเสร็จใช้งานได้

## ทวนคลาสที่แล้ว

- ฟังก์ชัน (`def` / `return`) ตั้งชื่อให้ขั้นตอน และเรียกใช้ซ้ำได้
- รายการ (`list`) เก็บหลายค่า · `append` เพิ่มต่อท้าย
- ผลรวม ค่ามากสุด ค้นหา เรียงลำดับ เขียนเองด้วยลูปได้ ก่อนใช้ `sum` `max` `in` `sorted`
- โปรแกรมรุ่นที่ 3: [bill_v3.py](../03-functions-lists-algorithms/examples/bill_v3.py) เก็บประวัติบิล แล้วสรุปตอนปิด

## โจทย์วันนี้

พนักงานพิมพ์ราคาผิดเป็นตัวอักษร โปรแกรมรุ่นที่ 3 ก็พังทันที และลูกค้าที่มาเป็นกลุ่มอยากรู้ว่าต้องจ่ายคนละเท่าไร ชั่วโมงแรกเราจะอ่านข้อผิดพลาดและทำให้โปรแกรมไม่พัง ชั่วโมงที่สองเราจะสร้างฟีเจอร์ "หารบิลกับเพื่อน" ร่วมกับ AI

**เมื่อโปรแกรมพัง:**
1. อ่านบรรทัดสุดท้ายของข้อความแจ้งข้อผิดพลาดก่อน ว่าเป็นข้อผิดพลาดชนิดไหน

2. ถ้ามากกว่า 1 คน เอายอดที่ต้องจ่ายหารจำนวนคน
3. แสดงว่าแต่ละคนต้องจ่ายเท่าไร

## แปลงเป็นโค้ด (Python)

### ชั่วโมงที่ 1: อ่านข้อความแจ้งข้อผิดพลาด

### 1. โปรแกรมพังหน้าตาเป็นอย่างไร

รันโปรแกรมรุ่นที่ 3 แล้วพิมพ์ราคาเป็น `abc`:

**ผลที่ได้:**
```
ราคาต่อชิ้น (บาท, 0 = ปิด): abc
Traceback (most recent call last):
  File "...\bill_v3.py", line 40, in <module>
    price = float(input("ราคาต่อชิ้น (บาท, 0 = ปิด): "))
            ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
ValueError: could not convert string to float: 'abc'
```

ข้อความนี้เรียกว่า **traceback** (ข้อความแจ้งข้อผิดพลาด) อ่านจากล่างขึ้นบน:
- **บรรทัดสุดท้าย** บอกชนิดและสาเหตุ: `ValueError` แปลงข้อความ `'abc'` เป็นตัวเลขไม่ได้
- **`line 40`** บอกว่าพังที่บรรทัดไหนของไฟล์ (ตำแหน่งไฟล์ `...` ของแต่ละเครื่องจะต่างกัน)

### 2. ข้อผิดพลาดที่เจอบ่อย

| ชนิด | แปลว่า | ตัวอย่างสาเหตุ |
|---|---|---|
| `ValueError` | ค่าใช้ไม่ได้ | `float("abc")` |
| `NameError` | ไม่รู้จักชื่อนี้ | พิมพ์ชื่อตัวแปรผิด เช่น `totl` แทน `total` |
| `TypeError` | ชนิดข้อมูลไม่เข้ากัน | เอาข้อความบวกตัวเลข `"ยอด " + 150` |
| `SyntaxError` | เขียนผิดไวยากรณ์ | ลืม `:` ท้าย `if` หรือวงเล็บไม่ครบ |
| `IndentationError` | เยื้องบรรทัดผิด | ลืมเยื้องบรรทัดใต้ `if` |

### 3. ไม่ให้พัง: `try` / `except`

```python
try:
    price = float("abc")
    print(price)
except ValueError:
    print("กรุณาพิมพ์ตัวเลข")
```

**ผลที่ได้:**
```
กรุณาพิมพ์ตัวเลข
```

`try` แปลว่า ลองทำ · `except ValueError` แปลว่า ถ้าเกิด `ValueError` ให้ทำส่วนนี้แทนการพัง

เอาไปทำเป็นฟังก์ชันที่ถามซ้ำจนกว่าจะได้ตัวเลข:

```python
def ask_number(prompt):
    while True:
        try:
            return float(input(prompt))
        except ValueError:
            print("กรุณาพิมพ์ตัวเลข")

price = ask_number("ราคาต่อชิ้น (บาท, 0 = ปิด): ")
print(price)
```

**ผลที่ได้** (พิมพ์ `abc` แล้ว `300`):
```
ราคาต่อชิ้น (บาท, 0 = ปิด): abc
กรุณาพิมพ์ตัวเลข
ราคาต่อชิ้น (บาท, 0 = ปิด): 300
300.0
```

### ชั่วโมงที่ 2: สร้างฟีเจอร์หารบิลกับ AI

ทำตาม 5 ขั้นนี้ทุกครั้งที่ให้ AI ช่วยเขียน:

1. **เขียนขั้นตอนเอง** — ใช้ขั้นตอนหารบิลข้างบน
2. **ขอ AI แค่ฟังก์ชันเดียว** ไม่ขอทั้งโปรแกรม พิมพ์ในแชต:
   ```
   เขียนฟังก์ชัน Python ชื่อ split_bill(pay, people) ที่คืนค่ายอดที่แต่ละคนต้องจ่าย เขียนแบบง่ายสำหรับมือใหม่
   ```
3. **อ่านทีละบรรทัด** — ต้องอธิบายได้ว่าทุกบรรทัดทำอะไร ถ้าอ่านไม่ออก ให้ถาม AI ต่อ หรือขอให้เขียนให้ง่ายลง
4. **ทดสอบกับคำตอบที่รู้อยู่แล้ว** — 900 บาท หาร 4 คน ต้องได้ 225

   ```python
   def split_bill(pay, people):
       return pay / people

   print(split_bill(900, 4))
   ```

   **ผลที่ได้:**
   ```
   225.0
   ```
5. **ใส่เข้าโปรแกรม** — ต่อท้ายการคิดเงินแต่ละบิล

### 4. รวมเป็นโปรแกรมคิดเงิน รุ่นที่ 4 (ฉบับเสร็จ)

```python
# โปรแกรมคิดเงิน รุ่นที่ 4 (จบคลาส 04) — ฉบับเสร็จ
# เพิ่มจากรุ่นที่ 3: พิมพ์ผิดแล้วถามใหม่ และหารบิลกับเพื่อน (ฟีเจอร์ที่สร้างร่วมกับ AI)
# พิมพ์ราคา 0 แล้วจะสรุปทุกบิลก่อนปิด


def ask_number(prompt):
    while True:
        try:
            return float(input(prompt))
        except ValueError:
            print("กรุณาพิมพ์ตัวเลข")


def calc_discount(total):
    if total >= 1000:
        return total * 10 / 100
    elif total >= 500:
        return total * 5 / 100
    else:
        return 0


def split_bill(pay, people):
    return pay / people


def my_sum(history):
    result = 0
    for amount in history:
        result = result + amount
    return result


def my_max(history):
    largest = 0
    for amount in history:
        if amount > largest:
            largest = amount
    return largest


def summary(history):
    print(f"จำนวนบิล {len(history)} · รวม {my_sum(history):.2f} บาท · บิลสูงสุด {my_max(history):.2f} บาท")
    parts = []
    for amount in sorted(history):
        parts.append(f"{amount:.2f}")
    print("เรียงจากน้อยไปมาก: " + ", ".join(parts))


history = []
while True:
    price = ask_number("ราคาต่อชิ้น (บาท, 0 = ปิด): ")
    if price == 0:
        summary(history)
        print("ปิดโปรแกรม")
        break
    qty = ask_number("จำนวนชิ้น: ")
    total = price * qty
    discount = calc_discount(total)
    pay = total - discount
    print(f"ยอดรวม {total:.2f} บาท · ส่วนลด {discount:.2f} บาท · ต้องจ่าย {pay:.2f} บาท")
    history.append(pay)
    people = ask_number("หารกี่คน (1 = ไม่หาร): ")
    if people > 1:
        print(f"คนละ {split_bill(pay, people):.2f} บาท")
```

ตั้งแต่รุ่นนี้ จำนวนชิ้นถามด้วย `ask_number` แทน `int()` จึงพิมพ์ทศนิยมได้ เช่น `2.5` สำหรับของที่ขายเป็นกิโลกรัม

**ผลที่ได้** (พิมพ์ `abc` · `300` `2` หาร `1` · `1000` `1` หาร `4` · `60` `2` หาร `1` · แล้ว `0`):
```
ราคาต่อชิ้น (บาท, 0 = ปิด): abc
กรุณาพิมพ์ตัวเลข
ราคาต่อชิ้น (บาท, 0 = ปิด): 300
จำนวนชิ้น: 2
ยอดรวม 600.00 บาท · ส่วนลด 30.00 บาท · ต้องจ่าย 570.00 บาท
หารกี่คน (1 = ไม่หาร): 1
ราคาต่อชิ้น (บาท, 0 = ปิด): 1000
จำนวนชิ้น: 1
ยอดรวม 1000.00 บาท · ส่วนลด 100.00 บาท · ต้องจ่าย 900.00 บาท
หารกี่คน (1 = ไม่หาร): 4
คนละ 225.00 บาท
ราคาต่อชิ้น (บาท, 0 = ปิด): 60
จำนวนชิ้น: 2
ยอดรวม 120.00 บาท · ส่วนลด 0.00 บาท · ต้องจ่าย 120.00 บาท
หารกี่คน (1 = ไม่หาร): 1
ราคาต่อชิ้น (บาท, 0 = ปิด): 0
จำนวนบิล 3 · รวม 1590.00 บาท · บิลสูงสุด 900.00 บาท
เรียงจากน้อยไปมาก: 120.00, 570.00, 900.00

```

## เรื่องเดียวกันใน JavaScript

ข้อผิดพลาดใน JavaScript มีกับดักที่ต่างจาก Python: แปลง `"abc"` เป็นตัวเลขแล้ว **ไม่พัง** แต่ได้ค่า `NaN` (Not a Number แปลว่า ไม่ใช่ตัวเลข) ออกมาเงียบ ๆ ต้องตรวจเองด้วย `Number.isNaN` ส่วนชื่อฟังก์ชันพิมพ์ผิดจะพัง และจับได้ด้วย `try` / `catch` เหมือน `try` / `except`

```js
// คลาส 04 แบบ JavaScript: ข้อผิดพลาดสองแบบที่ JavaScript ต่างจาก Python

// กับดักที่ 1: แปลงข้อความที่ไม่ใช่ตัวเลข JavaScript ไม่ฟ้อง แต่ได้ NaN (Not a Number)
const price = Number("abc");
console.log(price);
if (Number.isNaN(price)) {
  console.log("กรุณาพิมพ์ตัวเลข");
}

// กับดักที่ 2: เรียกฟังก์ชันที่ไม่มีอยู่ (พิมพ์ชื่อผิด) แล้วจับข้อผิดพลาดด้วย try / catch
function calcDiscount(total) {
  if (total >= 500) {
    return total * 5 / 100;
  }
  return 0;
}

try {
  console.log(calcDiscont(600));
} catch (error) {
  console.log(`เกิดข้อผิดพลาด: ${error.message}`);
}

console.log(calcDiscount(600));
```

รันด้วย `node bill_v4.js`

**ผลที่ได้:**
```
NaN
กรุณาพิมพ์ตัวเลข
เกิดข้อผิดพลาด: calcDiscont is not defined
30
```

| Python | JavaScript | ความหมาย |
|---|---|---|
| `float("abc")` พัง: `ValueError` | `Number("abc")` ไม่พัง ได้ `NaN` | แปลงข้อความเป็นตัวเลขไม่ได้ |
| `try:` / `except ValueError:` | `try { } catch (error) { }` | ลองทำ ถ้าพังให้ทำอีกส่วน |
| `NameError: name 'x' is not defined` | `x is not defined` | ไม่รู้จักชื่อนี้ |

## แบบฝึกหัด: ซ่อมโค้ด 3 ชิ้น

แต่ละชิ้นรันแล้วพัง ให้ทำตามขั้นตอนเมื่อโปรแกรมพัง: อ่านบรรทัดสุดท้าย ดูเลขบรรทัด แก้ แล้วรันให้ได้ผลตามที่บอก

### ชิ้นที่ 1

```python
total = 150
print(totl)
```

ข้อความที่ได้:
```
Traceback (most recent call last):
  File "...\bill.py", line 2, in <module>
    print(totl)
          ^^^^
NameError: name 'totl' is not defined. Did you mean: 'total'?
```

แก้แล้วต้องได้: `150`

<details>
<summary>ดูเฉลย</summary>

บรรทัดที่ 2 พิมพ์ชื่อตัวแปรผิด `totl` ต้องเป็น `total` (Python ยังช่วยเดาให้ว่า `Did you mean: 'total'?`)

```python
total = 150
print(total)
```

ผลที่ได้:
```
150
```

</details>

### ชิ้นที่ 2

```python
print("ยอด " + 150)
```

ข้อความที่ได้:
```
Traceback (most recent call last):
  File "...\bill.py", line 1, in <module>
    print("ยอด " + 150)
          ~~~~~~~^~~~~
TypeError: can only concatenate str (not "int") to str
```

แก้แล้วต้องได้: `ยอด 150`

<details>
<summary>ดูเฉลย</summary>

เอาข้อความ (`str`) ไปบวกกับตัวเลข (`int`) ไม่ได้ ต้องแปลงตัวเลขเป็นข้อความก่อนด้วย `str()` หรือใช้ f-string

```python
print("ยอด " + str(150))
```

ผลที่ได้:
```
ยอด 150
```

</details>

### ชิ้นที่ 3

```python
price = 50
if price > 0:
print("มีราคา")
```

ข้อความที่ได้:
```
  File "...\bill.py", line 3
    print("มีราคา")
    ^
IndentationError: expected an indented block after 'if' statement on line 2
```

แก้แล้วต้องได้: `มีราคา`

<details>
<summary>ดูเฉลย</summary>

บรรทัดที่ 3 อยู่ใต้ `if` แต่ไม่ได้เยื้อง ต้องเว้นหน้า 4 ช่อง

```python
price = 50
if price > 0:
    print("มีราคา")
```

ผลที่ได้:
```
มีราคา
```

</details>

## ช่วงใช้ AI

ชั่วโมงที่สองทั้งชั่วโมงคือช่วงใช้ AI (5 ขั้นข้างบน) และเพิ่มอีกหนึ่งอย่าง:

1. เอาข้อความแจ้งข้อผิดพลาดของชิ้นใดชิ้นหนึ่งในแบบฝึกหัด ไปวางในแชต AI แล้วพิมพ์ต่อท้าย:
   ```
   ข้อผิดพลาดนี้เกิดจากอะไร และควรแก้อย่างไร
   ```
2. อย่าเพิ่งเชื่อ **พิสูจน์** ก่อน: แก้ตามที่ AI บอก แล้วรันจริง ได้ผลตามที่แบบฝึกหัดบอกไหม
3. ถ้าไม่ได้ ให้ส่งข้อความแจ้งข้อผิดพลาดใหม่กลับไปให้ AI แล้วทำซ้ำ
4. ห้ามส่งรหัสผ่าน ข้อมูลส่วนตัว หรือโค้ดจากที่ทำงานให้ AI

## สรุป

- โปรแกรมพัง อ่านบรรทัดสุดท้ายก่อน แล้วดูเลขบรรทัด · เดา → `print` ดูค่าจริง → แก้ → รันใหม่
- `try` / `except` ทำให้โปรแกรมไม่พังเมื่อพิมพ์ผิด
- ให้ AI เขียนทีละฟังก์ชัน อ่านให้เข้าใจ และทดสอบกับคำตอบที่รู้อยู่แล้ว ก่อนใส่เข้าโปรแกรม
